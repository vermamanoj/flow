# Proxi Flow - Vision

## The Core Philosophy
"Teach once, correct live, approve safely, reuse forever."

Proxi Flow is a voice-first visual workflow assistant designed to be a trusted productivity partner. It is not a generic chatbot or a blind automation script. It is a highly visible, collaborative agent that understands the user's workspace, plans actions, and executes them while keeping the user in full control.

## The Problem
Current AI assistants either talk well but cannot act, or automate tasks but are hard to control and trust (e.g., brittle "computer use" agents that blindly click X/Y coordinates). 

## The Solution
Proxi Flow bridges this gap by using the Gemini Multimodal Live API combined with **Custom Semantic Tools**. 
1. **Voice-First & Multimodal:** The user speaks naturally while the agent "sees" the screen.
2. **Live Collaboration:** The user can interrupt the agent mid-sentence or mid-action to correct its course.
3. **Approval-First Execution:** The agent pauses before risky actions (like sending an email or deleting data) to ask for explicit approval.
4. **Reusable Workflows:** Once a task is successfully completed, the exact semantic steps are saved as a reusable workflow, turning a one-off interaction into a permanent productivity boost.

## Hackathon Positioning (Gemini Live Agent Challenge)
- **Primary Category:** UI Navigator
- **Secondary Flavor:** Live Agent
- **Differentiator:** Moving beyond brittle DOM-crawling by using semantic custom tools and focusing on enterprise-grade trust (approvals & reusability).
