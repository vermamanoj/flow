# Proxi Flow - Feature Set

## 1. Voice Interaction (Live API)
- Real-time, interruptible voice conversations using the Gemini Live API.
- Raw PCM audio streaming for low-latency communication.
- Agent has a distinct, natural voice and handles interruptions gracefully.

## 2. Workspace Understanding (Multimodal Vision)
- Continuous visual capture of the "Demo Workspace" (mock UI).
- Frames are streamed to Gemini at 1fps as base64 JPEGs.
- The agent uses this visual context to ground its responses and actions.

## 3. Semantic Action Execution
- Uses custom semantic tools (e.g., `navigate_view`, `draft_email`, `extract_action_items`) instead of brittle X/Y clicks.
- Actions instantly update the React state in the Demo Workspace.

## 4. Dynamic Planning & Execution Log
- **Current Plan:** A visible checklist of 3-5 steps generated by the agent, updating in real-time.
- **Execution Log:** A chronological, human-readable timeline of events (utterances, screenshots analyzed, tools called, approvals).

## 5. Interruption Handling
- Users can interrupt verbally ("No, wait, do March instead").
- The agent stops speaking, freezes the action queue, updates the state to `INTERRUPTED`, and replans.

## 6. Approval Gate
- Before risky actions (e.g., `send_email`), the agent emits a `request_approval` tool call.
- The UI enters `PAUSED_FOR_APPROVAL` state, showing a modal.
- Execution resumes only after user approval or denial.

## 7. Workflow Save and Replay
- Successful task executions can be saved as reusable workflows.
- Workflows are stored in Firebase/Firestore (Google Cloud integration).
- Users can click "Run" on a saved workflow to replay the exact semantic steps without needing to re-prompt the AI.
