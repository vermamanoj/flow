# Proxi Flow - Feature Set

## 1. Voice Interaction (Gemini Live API)
- Real-time, interruptible voice conversations using Gemini 2.5 Flash native audio.
- Raw 16kHz PCM audio streaming from microphone to backend to Gemini.
- 24kHz PCM audio playback from Gemini responses.
- Agent has a distinct voice (Zephyr) with a confident, helpful persona.
- Rich system instruction with workspace/desktop context and safety rules.

## 2. Workspace Understanding (Multimodal Vision)
- Continuous visual capture of the Demo Workspace (MockCRM) via `modern-screenshot`.
- Frames streamed to Gemini as base64 JPEGs (~every 2 seconds).
- Agent uses visual context to ground its responses and understand the workspace state.

## 3. Semantic Workspace Tools (5 tools, frontend-executed)
- `navigate_view` — Switch between inbox, notes, and drafts views.
- `draft_content` — Create email drafts staged for review.
- `request_approval` — Pause and ask user for explicit permission.
- `update_plan` — Display/update the multi-step execution plan.
- `save_workflow` — Save the current action sequence as a reusable workflow.

## 4. Real Desktop Tools (5 tools, server-executed)
- `take_screenshot` — Capture the real desktop screen via `screenshot-desktop`.
- `run_command` — Execute shell commands via `child_process` (PowerShell/Bash).
- `open_url` — Open URLs in the default browser via `open`.
- `list_files` — List directory contents on the filesystem.
- `read_file` — Read text file contents (max 100KB).

## 5. Hybrid Tool Routing
- Gemini's tool calls are intelligently routed by the backend:
  - Workspace tools → forwarded to frontend React state via WebSocket.
  - Desktop tools → executed server-side, results sent directly back to Gemini.
- Frontend receives `serverToolExec` notifications for the execution log.

## 6. Command Guard (Safety)
- Server-side regex patterns block dangerous commands: `rm -rf`, `format`, `shutdown`, `del /s`, `mkfs`, etc.
- System instruction reinforces safety guidelines.
- Approval gate required before any sensitive or destructive actions.

## 7. Dynamic Planning & Execution Log
- **Current Plan:** Visible step-by-step checklist generated by the agent, updating in real-time.
- **Live Transcript:** Horizontal scrolling strip showing recent user/agent/action messages.
- **Execution Log:** Dark-themed timeline with icons for every event type.

## 8. Interruption Handling
- Users can interrupt verbally or click the Interrupt button.
- Audio playback stops immediately, state updates to `INTERRUPTED`.
- Gemini Live API handles voice overlap natively.

## 9. Approval Gate
- Before risky actions, the agent emits a `request_approval` tool call.
- The UI enters `PAUSED_FOR_APPROVAL` state with a prominent modal.
- Execution resumes only after user explicitly approves or denies.

## 10. Workflow Save and Replay
- Successful task sequences saved as reusable workflows to Firebase Firestore.
- Google Sign-In for user authentication and ownership.
- One-click replay from the sidebar — replays exact semantic steps with visual feedback.

## 11. State Machine (8 States)
- `IDLE` → `LISTENING` → `THINKING` → `SPEAKING` → `ACTING` → `PAUSED_FOR_APPROVAL` → `INTERRUPTED` → `SAVING_WORKFLOW`
- Each state has a distinct visual indicator in the header with icon and color.
